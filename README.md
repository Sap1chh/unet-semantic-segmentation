# U-Net Semantic Segmentation

Проєкт з реалізації U-Net для семантичної сегментації зображень.

## 📌 Мета

## 🧠 Технології
- Python
- TensorFlow / PyTorch
- NumPy
- Matplotlib
- OpenCV
